# Sales Performance Analysis Report

## 📊 Project Overview

This project analyzes sales data from 2020 to 2025 to understand sales performance, trends, and category-wise insights.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Data Cleaning
- Data Analysis
- PowerBi
- Data Visualazation

## 📈 Analysis

- Year-wise Sales Analysis
- Category-wise Sales Analysis
- Profit Analysis
- Sales Trends

## Project Overview

This project focuses on analyzing sales data from 2020 to 2025 using Microsoft Excel. The analysis includes data cleaning, data transformation, and visualization to identify sales trends, category-wise performance, and overall business insights.

The report helps understand sales performance over the years and provides meaningful insights that can support better business decisions.

## Data Sources

The dataset used in this project was collected from publicly available online sources. The data contains sales-related information from 2020 to 2025 and was used for data cleaning, analysis, and visualization in Microsoft Excel.

## Problem Statement

* Analyze sales performance from 2020 to 2025.
* Identify year-wise sales trends and patterns.
* Analyze sales performance across different categories.
* Compare category-wise sales and profit.
* Analyze state-wise sales performance.
* Identify high-performing and low-performing states.
* Identify top-performing and underperforming categories.
* Generate meaningful insights to support better business decisions.

## Data Processing Steps

1. **Data Collection**

   * Collected the sales dataset from a Google source.

2. **Data Analysis & Cleaning**

   * Analyzed the collected data using Microsoft Excel.
   * Removed duplicate records.
   * Used **TRIM** to remove unnecessary spaces.
   * Used **CLEAN** to remove unwanted or non-printable characters.
   * Checked the data for missing or inconsistent values.

3. **Data Transformation**

   * Transformed the data into a suitable format for analysis.
   * Used **Conditional Formatting** to highlight important data and identify patterns.

4. **Data Summarization**

   * Created **Pivot Tables** to summarize the data.
   * Used Pivot Tables for quick analysis and easy comparison of key metrics.

5. **Data Visualization**

   * Imported the processed data into **Power BI**.
   * Created reports and visualizations to present the analyzed data clearly.

6. **Interactive Analysis**

   * Added **Slicers** to make the report interactive.
   * Used category-based filtering to easily view the required information.

7. **Final Report**

   * Created an interactive Power BI report to present key trends, comparisons, and business insights.

## Analytics and Visualization

* **Sales Report:** Created an interactive sales report to present key business metrics and performance.
* **KPI Card:** Used KPI cards to display important summary metrics such as sales and profit.
* **Year-wise & Category-wise Turnover:** Used a **Line Chart** to analyze turnover trends across different years and categories.
* **Profit Margin Analysis:** Used a **Pie Chart** to visualize the profit margin distribution across categories.
* **Category-wise Profit Analysis:** Used a **Column Chart** to compare category-wise sales and profit performance.
* **Category Movement Analysis:** Created a **Matrix Table** to identify the maximum and minimum movement across different categories.
* **Interactive Filtering:** Used slicers to filter and analyze the report based on selected categories.

### Key Insight

* The visualizations help identify **sales trends, category performance, profit contribution, and high- and low-performing categories**.
