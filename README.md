# Sales Performance Analysis Report

## 📊 Project Overview

This project analyzes sales data from 2020 to 2025 to understand sales performance, trends, and category-wise insights.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Data Cleaning
- Data Analysis
- PowerBi
- Data Visualazation

## 📈 Analysis

- Year-wise Sales Analysis
- Category-wise Sales Analysis
- Profit Analysis
- Sales Trends

## Project Overview

This project focuses on analyzing sales data from 2020 to 2025 using Microsoft Excel. The analysis includes data cleaning, data transformation, and visualization to identify sales trends, category-wise performance, and overall business insights.

The report helps understand sales performance over the years and provides meaningful insights that can support better business decisions.

## Data Sources

The dataset used in this project was collected from publicly available online sources. The data contains sales-related information from 2020 to 2025 and was used for data cleaning, analysis, and visualization in Microsoft Excel.

## Problem Statement

* Analyze sales performance from 2020 to 2025.
* Identify year-wise sales trends and patterns.
* Analyze sales performance across different categories.
* Compare category-wise sales and profit.
* Analyze state-wise sales performance.
* Identify high-performing and low-performing states.
* Identify top-performing and underperforming categories.
* Generate meaningful insights to support better business decisions.

| **Attribute**      | **Data Type**     | **Description**                                                       |
| ------------------ | ----------------- | --------------------------------------------------------------------- |
| **Order ID**       | Text              | A unique identifier assigned to each order.                           |
| **Order Date**     | Date              | The date on which the order was placed.                               |
| **Customer Name**  | Text              | The name of the customer who placed the order.                        |
| **Amount**         | Decimal / Numeric | The total sales amount generated from the order.                      |
| **Profit**         | Decimal / Numeric | The profit earned from the order.                                     |
| **Quantity**       | Integer           | The number of products purchased in the order.                        |
| **Subcategory**    | Text              | The specific product subcategory associated with the order.           |
| **Category**       | Text              | The main category of the product.                                     |
| **Profitability**  | Text / Category   | Indicates whether the order or product is profitable or unprofitable. |
| **Earning Status** | Text / Category   | Indicates the earning status based on the profit generated.           |
| **Payment Mode**   | Text / Category   | The method used by the customer to make the payment.                  |
| **CP**             | Decimal / Numeric | The cost price of the product.                                        |
| **State**          | Text              | The state where the customer or order is located.                     |
| **Price per Unit** | Decimal / Numeric | The selling price of one unit of the product.                         |
| **Profit Margin**  | Decimal / Numeric | The percentage of profit earned relative to the sales amount.         |
